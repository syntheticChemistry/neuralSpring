## Conventions

- One directory per fossil, named `{pattern}_{era}_{month}{year}/`
- Each directory contains a `README.md` with provenance metadata
- Fossils are never modified after archival
- Source code in fossils is dead code — not compiled, not tested
- Provenance links back to the session and handoff that triggered fossilization
