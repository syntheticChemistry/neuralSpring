# Fossil Record: neuralspring_primal Server (Prokaryotic)

**What:** Standalone `neuralspring` primal server binary — JSON-RPC 2.0
IPC server with biomeOS integration, spectral analysis, coralForge,
and GPU dispatch capabilities.

**When:** May 2026, Interstadial Primordial Extinction event.

**Why:** The primal server will be absorbed into the UniBin's `serve`
subcommand in the next evolution wave. This fossil preserves the
pre-extinction directory structure:
- `main.rs` — entry point with CLI, socket binding, heartbeat loop
- `biomeos.rs` — biomeOS orchestrator registration
- `discovery.rs` — socket directory resolution
- `handlers.rs` — JSON-RPC method dispatch
- `rpc.rs` — protocol framing
- `tower.rs` — tower mode capabilities
- `spectral.rs` — spectral analysis handlers
- `folding.rs` — coralForge folding handlers

**Superseded by:** `neuralspring-unibin serve` (future absorption).

**Note:** The primal server continues to function as `neuralspring`
binary. This fossil records the pre-UniBin state for provenance.

**Provenance:** Session S193, neuralSpring V143.
